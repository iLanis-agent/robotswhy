RobotsWhy

Paste a robots.txt, name the crawler, list URLs. RobotsWhy says which are allowed, and for each one which rule decided it, following RFC 9309: matching group, wildcards, longest match wins, Allow wins ties.
Follows RFC 9309 (read in full): groups and merging of groups for the same product token, case-insensitive token match, case-sensitive paths, percent-encoding normalization, * and $, the most specific match wins, Allow wins a tie, /robots.txt always allowed, and the fetch results (4xx allows all, 5xx or unreachable disallows all). Where the RFC leaves a choice, this tool counts the specificity of a rule as the number of characters in the normalized rule, as Google does, including * and $. Real crawlers differ in places: some also match a product token as a prefix, some read Crawl-delay, and Google ignores rules that do not start with / or *. Match is on the path plus query string; fragments are dropped. Only product tokens are matched, not full User-Agent strings. Robots rules are a request to crawlers, not access control. Runs in your browser; nothing is fetched or sent.
